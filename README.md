# Calculadora de Honorários · Adonis Lima Advocacia

Calculadora de honorários previdenciários conforme a Tabela de honorários do escritório (Manual Operacional, Notion).

- Página única (`index.html`), sem dependências e sem salvar dados.
- Publicada pelo GitHub Pages.
- Calculadora de repasses em `repasses/` (imposto sobre o valor pago; comissões em cascata: indicação, depois advogado parceiro ou associado).
- Regras: benefício em geral (via administrativa e judicial por RPV ou precatório), revisão, salário-maternidade, auxílio-doença, curatela, análise e planejamento previdenciário.
